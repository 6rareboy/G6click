# G6click
G6click is the all-in-one automatic extreme debloat and optimization tool, designed to disable Telemetry, Unnecessary Services, and apply various tweaks to improve the user's performance! G6click's primary goal is to debloat all aspects of the user's pc, ranging from basic telemetry to system apps. G6click also offers a wide array of system tweaks, like GPU Tweaks, Latency Tweaks, Power Tweaks and more.
